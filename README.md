## Status
Scaffolded (folder structure + instruction stubs). Not yet implemented — component files contain TODO instructions, not working code.

## Setup (once implementation begins)
```bash
npm install
npm run dev      # http://localhost:5173
npm run build     # outputs dist/
```

> The Vite base files (`index.html`, `package.json`, `vite.config.js`, `tailwind.config.js`, `postcss.config.js`, `src/main.jsx`, `src/App.jsx`, `src/index.css`) are generated by the scaffold step (`npm create vite@latest . -- --template react` + Tailwind plugin). The custom files already in place live under `src/components/` and `src/lib/`.

## Environment
Copy `.env.example` to `.env` and fill in:
- `VITE_POSTHOG_KEY` — Posthog project key
- `VITE_FORMSPREE_ID` — Formspree form id

Never commit `.env`.
